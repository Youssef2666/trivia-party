# 01 — عن المشروع

## ما هو «تريفيا بارتي»؟

لعبة أسئلة جماعية **مباشرة (Real-time)** بأسلوب Kahoot و Jackbox، مصممة للحفلات والتجمعات العائلية والسهرات:

- شخص واحد ينشئ الغرفة (المضيف) ويشارك رمزاً من 6 أحرف أو QR Code.
- الأصدقاء ينضمون من هواتفهم عبر نفس شبكة الـ Wi-Fi — **بدون تنزيل أي تطبيق وبدون إنترنت**.
- أسئلة سريعة بمؤقت، نقاط حسب السرعة، قدرات خاصة، جولات مفاجئة، وأصوات وتفاعلات حية.

### الفلسفة
1. **بدون إنترنت نهائياً**: كل شيء (الخطوط، الأيقونات، الأصوات، الشخصيات) مضمّن داخل المشروع. شغّل الخادم على أي لابتوب وستعمل اللعبة كاملة على شبكة محلية.
2. **الخادم هو الحَكَم**: المؤقت والتصحيح والنقاط كلها على الخادم — لا يمكن الغش من المتصفح، والإجابة الصحيحة لا تُرسل للاعبين قبل انتهاء السؤال.
3. **العربية أولاً**: واجهة RTL كاملة بخط Cairo، مع دعم إنجليزي كامل بزر واحد.
4. **بدون مكتبات واجهة**: Vanilla JS خالص — سهل الفهم والتعديل لأي مطوّر.

## البنية التقنية

| الطبقة | التقنية |
|---|---|
| الخادم | Node.js + Express + Socket.io 4 |
| الواجهة | Vanilla JS (ES5-style) + CSS مخصص، بدون أي Framework |
| التزامن | WebSockets مع مزامنة توقيت client↔server |
| الأصوات | WebAudio API (توليد صوتي برمجي — لا ملفات صوت) |
| قارئ الأسئلة | Web Speech API (صوت عربي/إنجليزي من النظام) |
| الشخصيات | 20 شخصية SVG مرسومة يدوياً بتعابير متحركة |
| الخطوط | Cairo (Variable 400–900) مضمّن woff2 |

### خريطة الملفات
```
trivia-party/

│   ├── ScoringEngine.js  # معادلات النقاط والخصم (دوال نقية)
│   └── questions/        # بنك الأسئلة مقسّم ملفات (375 سؤالاً)
│       ├── index.js      # لودر يجمع كل ملفات json تلقائياً
│       ├── general.json  # الفئات العامة

    ├── css/              # fonts / variables / base / components / animations
    ├── fonts/            # Cairo woff2 (عربي + لاتيني)
    ├── lang/             # ar.json + en.json (198 مفتاح ترجمة)
    └── js/
        ├── icons.js      # أيقونات SVG مضمّنة (بديل CDN)
        ├── avatars.js    # الشخصيات + سيارات السباق
        ├── sound.js      # محرك الصوت + الموسيقى + قارئ الأسئلة
        ├── i18n.js / utils.js / socket.js
        ├── app.js        # الراوتر + طبقة الحفلة (تفاعلات/تراكبات)

```

### آلة حالات الجولة (على الخادم)
```
LOBBY → STARTING → QUESTION_ACTIVE → REVEAL → LEADERBOARD ─┐
          ↑                                                │ (حسب النمط)
          └──────────────── rematch ◄─── GAME_END ◄────────┘
                                   ▲
                    TIEBREAKER_INTRO → QUESTION_ACTIVE (جولة الحسم)
```

### أهم أحداث الشبكة
| الحدث | الاتجاه | الوظيفة |
|---|---|---|
| `create_room` / `join_room` / `rejoin_room` | ⬆️ | إدارة الدخول |
| `update_settings` / `assign_team` / `kick_player` | ⬆️ (مضيف) | إعدادات الغرفة والفرق |
| `start_game` / `request_next` / `rematch` | ⬆️ (مضيف) | تدفق اللعبة |
| `submit_answer` `{optionIndex}` أو `{guess}` | ⬆️ | الإجابة (اختيار أو تخمين) |
| `use_powerup` / `use_item` | ⬆️ | القدرات الكلاسيكية / أسلحة السباق |
| `send_reaction` | ⬆️ | إيموجي حي (بحد أقصى واحد كل 800ms) |
| `question_started` / `question_ended` / `leaderboard_updated` | ⬇️ | دورة السؤال |
| `player_eliminated` / `tiebreaker_starting` / `game_ended` | ⬇️ | اللحظات الكبرى |

## أنماط اللعب الخمسة

| النمط | الفكرة | ينتهي عندما |
|---|---|---|
| **كلاسيكي** | أسئلة ونقاط، مع سؤال ذهبي أخير ×2 وجولة جرس | تنتهي الجولات المحددة |
| **فرق** | أحمر ضد أزرق، مجموع الفريق يحسم، وتعادل الفرق = مبارزة بين نجمَي الفريقين | تنتهي الجولات |
| **البقاء** | كل N أسئلة يُقصى صاحب أدنى نقاط | يبقى لاعب واحد |
| **مضمار السباق** | أول من يصل لهدف النقاط يفوز، والبقية يكملون للترتيب — مع أسلحة 🚀🛡️🔥 | ينهي الجميع السباق |
| **المطاردة** | مطارد واحد ضد الجميع: جدار أحمر يتقدم بإجاباته الصحيحة، والهاربون يتسلقون لبوابة الأمان | يُحسم كل الهاربين (أمان أو إمساك) |

**جولات مشتركة**: جولة الجرس (الأسرع يخطفها)، جولات التخمين (أقرب رقم)، وجولة الحسم عند التعادل.

**شاشة العرض**: يحوّل جهاز المضيف إلى شاشة تقديم (السؤال والإحصائيات هناك)، وتتحول هواتف اللاعبين إلى أزرار ملونة عملاقة — تجربة استوديو حقيقية على التلفاز.

## التشغيل

```bash
npm install   # مرة واحدة (الحزم مضمّنة في النسخة المضغوطة)
npm start     # يطبع رابط الشبكة المحلية مثل http://192.168.1.15:3000
```

- `PORT=4000 npm start` لتغيير المنفذ.
- `/health` نقطة فحص جاهزية.

## كيف تضيف أسئلة؟

الأسئلة في مجلد `server/questions/` (ملف لكل حزمة). ثلاثة أنواع:

```jsonc
// اختيار من 4
{ "category": "football", "difficulty": "easy",
  "question": { "ar": "…؟", "en": "…?" },
  "options": [ { "ar": "أ", "en": "A" }, … 4 خيارات … ],
  "correctIndex": 0 }

// صح/خطأ (خياران فقط)
{ …نفس الشكل مع خيارين… }

// تخمين رقمي — أقرب إجابة تفوز
{ "type": "guess", "category": "general", "difficulty": "medium",
  "question": { "ar": "كم…؟", "en": "How many…?" },
  "answer": 206, "unit": { "ar": "عظمة", "en": "bones" } }
```

**الفئات الحالية**: كرة القدم (282 سؤالاً — الأكبر)، علوم، تاريخ، جغرافيا، مشاهير وفن، رياضة، تكنولوجيا، العالم العربي، ثقافة عامة.

**لإضافة حزمة أسئلة جديدة**: أنشئ ملف `server/questions/اسم-الحزمة.json` بمصفوفة أسئلة — اللودر يلتقطه تلقائياً عند تشغيل الخادم. لفئة جديدة كلياً أضف اسمها أيضاً في `lang/*.json` تحت `categories` وفي `ALL_CATEGORIES` داخل `screens/lobby.js` وإعدادات `GameRoom.js`.

**السمات**: المضيف يختار سمة الحفلة من اللوبي (نيون/رمضان/الملعب/آركيد) — التنفيذ في `public/css/themes.css` عبر `[data-theme=…]`، وإضافة سمة جديدة = كتلة CSS واحدة + اسم في القائمة.
